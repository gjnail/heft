# Code of Conduct

Be respectful and patient with everyone, including newcomers and people
writing in a second language. Criticize code and ideas, not people. Assume
good faith. Maintainers may decline changes; they should explain why.

Harassment, personal attacks, discriminatory language and sharing someone
else's private information (including paths or screenshots that reveal it)
aren't allowed in issues, pull requests or any other project space.

Maintainers may edit or remove comments and block people who break these
rules. To report a problem privately, contact the maintainer through their
GitHub profile ([@gjnail](https://github.com/gjnail)).

This is a short version of the ideas in the
[Contributor Covenant](https://www.contributor-covenant.org/).
