Startup, programs and registry

Windows

Three maintenance pages for Windows: what starts when you sign in, what's installed, and registry entries that point at things that are gone.

On this page
  • Startup
  • Programs
  • Updating programs
  • Registry
  • Backups

Items that affect every user on the PC, scheduled tasks and HKEY_LOCAL_MACHINE need administrator rights. Each page says so and offers Restart as administrator.

Startup

The Startup page lists everything that launches when you sign in: Run keys in the registry, Startup folders, and scheduled tasks that run at logon or boot. Each row shows the program, its publisher, the command it runs and where the entry lives. Use Filter to find one.

  • Turn an item off with its checkbox. This uses the same switch as Task Manager's Startup tab, so nothing is deleted and you can turn it back on any time.
  • Remove an entry for good with the bin button. Startup-folder shortcuts go to the Recycle Bin, scheduled tasks are deleted, and registry entries are deleted after a .reg backup is saved.

Run-once entries can only be removed, since Windows deletes them itself after they run.

Programs

The Programs page lists everything installed with the space it really takes. Installers often report their size wrong or not at all, so Heft measures each install folder. A size with a ~ in front is the installer's own figure, used when there's no folder to measure. Search by name or publisher, and sort by size, name, install date or publisher.

To uninstall a program:

  1. Press Uninstall. The program's own uninstaller opens, and Heft waits for it to finish.
  2. Heft then looks for folders it left behind and lists them.
  3. Tick what to remove and press Move to the Recycle Bin, or Keep everything.

Leftover suggestions are checked against the programs that are still installed. A folder is never suggested if it belongs to another program, is shared with one, or sits inside one, and a folder is never taken from a launcher's command line (such as a Steam game's uninstall link). Only the folder the installer itself recorded is ticked; folders that just share the program's name are listed unticked, so you can check them first.

The menu button on each row can open the install folder, Show in disk map (scan it on the Disk usage page), copy the uninstall command, or Remove from the list. That last one is for programs whose uninstaller no longer exists: Heft deletes the leftover registry entry after saving a .reg backup.

Updating programs

Press Check for updates and Heft asks winget, Windows' package manager, which programs have newer versions. Programs with an update get an Update button, and Update all updates everything at once after asking.

Installers run in a console window so you can see their prompts and license terms. This is the only time Heft uses the network.

Registry

Registry "cleaning" doesn't make Windows faster, and aggressive registry cleaners break things. Heft's Registry page is housekeeping, and it's deliberately narrow. Press Scan for issues to look for entries that point to programs, files or folders that no longer exist:

  • uninstall entries for removed programs;
  • startup entries for missing programs;
  • App Paths for missing programs (what Win+R uses to find them);
  • shared DLL counts for missing files;
  • installer folder references;
  • compatibility settings for missing programs;
  • cached names of missing programs.

Only the first four are ticked, because they have a visible effect (Apps & Features, startup, Win+R and uninstall bookkeeping). The rest are harmless clutter, listed for you to decide.

An entry only counts as broken when the file it names is provably gone. Network paths, missing drives and "access denied" are never treated as missing, and COM registrations and file associations are left alone entirely. Press Fix selected and Heft saves a backup, then removes the entries.

Backups

Every registry change Heft makes, on the Registry, Startup and Programs pages, is saved first as a .reg file in %LOCALAPPDATA%\Heft\backups. The Backups list at the bottom of the Registry page shows them all. Press Restore next to one to write the saved entries back, or Open folder to see the files. Entries for all users need administrator rights to restore.
