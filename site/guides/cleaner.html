The Cleaner

Windows · macOS · Linux

The Cleaner removes caches, temporary files and logs that programs recreate when they need them. It only looks in places it knows, and shows you every file before it removes anything.

Using the Cleaner

  1. Open the Cleaner page. Heft analyzes right away; this only reads, and takes a few seconds.
  2. Look over What to clean on the left. Each item shows how much it would free. Recommended ticks Heft's defaults (caches and temporary files only), and None clears everything.
  3. Click a row in the results to see exactly which files would be removed. Double-click a file to show it in Explorer. Back to all results returns to the list.
  4. Press Clean and confirm.

Some items are marked in the list:

  • ⏸ Close the program first. Heft skips a program's caches while it's running, so it never pulls files out from under it. Close it and press Analyze again.
  • 🛡 Needs administrator rights. System-wide locations such as Windows Update downloads and memory dumps need Restart as administrator.
  • ⚠ Has a side effect. Hover to see it. Cookies sign you out of every website, emptying the Recycle Bin is permanent, and developer caches download again on the next build. Apart from memory dumps, which only matter if you're troubleshooting crashes, none of these are ticked by default.

Your selection is remembered for next time. Programs that aren't installed are hidden, so the list only shows what's on your computer.

Cleaned files are deleted rather than moved to the Recycle Bin, because programs recreate them anyway and recycling caches would just move the clutter. The confirmation dialog says so.

What it covers

GroupExamples
SystemTemporary files, the Recycle Bin or Trash, thumbnail and shader caches, error reports and crash dumps, old logs. On Windows also Windows Update and Delivery Optimization downloads, setup logs and NVIDIA driver downloads.
BrowsersChrome, Edge, Firefox, Brave, Vivaldi, Opera and Chromium, plus Opera GX on Windows and Safari on macOS. The cache is ticked by default. On Windows, cookies, history, form history and the last session are there too, each with a note on what you'd lose.
ApplicationsDiscord, Slack, Teams, Spotify, Visual Studio Code, Cursor, Steam, Epic Games Launcher, JetBrains IDEs, Adobe and Java.
Developer toolsPackage and build caches for npm, Yarn, Bun, pip, Cargo, Go, Gradle, NuGet, Deno, Composer and Electron. On macOS also Homebrew, Xcode (DerivedData, simulator caches, simulators for runtimes you no longer have, device support files) and CocoaPods.
Privacy (Windows)Recent items, Run dialog and Explorer address bar history, the clipboard and the DNS cache. None are ticked by default.

Heft has no rules for saved passwords, and none for the Windows Prefetch folder: clearing Prefetch makes programs start more slowly, not faster.

How it stays safe

  • Every rule names exact locations. There's no searching the disk for anything that looks like *.tmp.
  • A rule is skipped, not guessed, if its location can't be found or would point at a top-level user or system folder.
  • Links and junctions are never followed, so a cache folder can't lead Heft somewhere else.
  • Files that are in use are skipped, never forced.
  • Cleaning removes the files the analysis found, not whatever turns up in the folder later.

System caches on Linux

On Linux, some caches belong to the system, and the right way to clear them is the tool that owns them. Heft runs those tools instead of deleting files itself:

  • apt-get clean and dnf clean packages for package caches;
  • journalctl --vacuum-time=2weeks for old system logs;
  • removing old, disabled snap revisions;
  • flatpak uninstall --unused for runtimes no app needs.

Heft shows the estimated saving first. Commands that need root go through pkexec, which asks for your password with your desktop's own prompt. On macOS, the Xcode simulator cleanup runs xcrun simctl delete unavailable in the same spirit.

Weekly cleaning (Windows)

At the bottom of the Cleaner page, tick Clean the selected items every Sunday. Heft adds a Windows scheduled task called Heft\Weekly clean that runs heft --clean with your current selection. If you set it up while running as administrator, the task runs elevated too, so administrator-only items are included.

Untick the box to remove the task. On macOS and Linux, you can schedule heft --clean yourself; see Command line.

WSL and Docker disks (Windows)

WSL 2 distros and Docker Desktop keep Linux's files in a virtual disk (.vhdx) that grows as Linux writes data but never shrinks when the data is deleted. The WSL and Docker disks section finds them and shows their size.

  1. Tick the disks to compact and press Compact.
  2. Heft can first run fstrim inside each WSL distro, so the disk knows which space Linux has freed.
  3. It shuts WSL down with wsl --shutdown, then compacts every disk with diskpart in one go. Windows asks for administrator permission once.

Large disks can take minutes. When it's done Heft shows each disk's size before and after. Disks already set to sparse shrink by themselves and can't be ticked.

Windows' own tools

Some cleanup belongs to Windows. The Cleaner page has shortcuts to:

  • Storage Sense, Windows' automatic cleanup settings;
  • Disk Cleanup, which can remove a previous Windows installation (Windows.old);
  • Component store cleanup, which runs DISM as administrator to remove superseded Windows updates from WinSxS. It opens a console window and can take a while.
